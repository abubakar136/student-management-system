# Student Management System

## Project Overview

The Student Management System is a web application developed to manage student records. It allows users to add, view, search, update, and delete student information.

## Technologies Used

- **Frontend:** React.js
- **Backend:** Node.js and Express.js
- **Database:** MongoDB
- **Development Tool:** Visual Studio Code

## Features

- User authentication
- Add new students
- View student records
- Search for students
- Update student information
- Delete student records
- Dashboard statistics
- Recent student registrations
- Form validation
- Loading indicators
- Responsive user interface
- Database persistence

## Project Structure

- `client/` — React frontend
- `server/` — Express backend

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/abubakar136/student-management-system.git
cd student-management-system
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Set Up the Frontend

```bash
cd client
npm install
npm run dev
```

### 3. Set Up the Backend

Open another terminal:

```bash
cd server
npm install
npm run dev
```

Configure the required environment variables in a local `.env` file according to your backend configuration. Do not upload secrets or passwords to GitHub.
